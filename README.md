# Prêmio dos Gêmeos

Sistema de demonstração com cadastro de nome, CPF e WhatsApp, pagamento Pix manual, confirmação pelo administrador, geração de combinações e envio pelo WhatsApp Cloud API oficial quando configurada.

## Instalação
npm install
npm start

Site: /  |  Painel: /admin.html

Não coloque tokens ou senhas reais no código. O Pix é manual e o envio automático do WhatsApp exige configuração da API oficial. Verifique as regras legais aplicáveis antes de publicar.
